# 山东大学青岛校区 · 春日夕照

把压缩包完整解压到本地可写目录，例如 `D:\山青\Blender`。打开 **山东大学青岛校区.blend** 可编辑建筑、网格、植被、材质、灯光和相机。原生工程用 Blender 4.3 保存，47 张图像已经打包，单独复制该文件也能打开。双击 **打开青岛校区.html** 可以离线漫游、点选地点、切换“仅看建模区”。

## 视频怎么重新采集

在 Windows x64 上双击 **开始采集校园漫游.cmd**，输入 **1** 即按终版航线重新采集 3840 × 2160、60 fps 的横屏视频。2 为 4K30，3 为 1080p30。入口会使用工程内的 Python、Chrome、FFmpeg 和 FFprobe。三维场景通过 WebGL / Direct3D 11 绘制，按固定时间逐帧生成，Chrome 用 WebCodecs 编码，FFmpeg 合并。显卡需配有可用驱动。可先在工程目录的 PowerShell 执行 `.\开始采集校园漫游.cmd --check` 检查环境和航线。

新片写入本工程的 `手动采集\`，分片与日志写入 `.jobs\手动采集\`。中断后重新选同一规格可续采。已有同名成片时入口会提示改名。完成并核验成片后，可以清理该次分片。

原始终版 MP4 单独放在压缩包旁，时长 **2 分 11.5 秒**，共 **7,890 帧**。画面含 16 个随楼标记与 14 段左下角介绍。成片 SHA-256 为 `b200162295fc97890ae52ecd90e9d3e520d2be397e701e22e769b97837243ad4`。原始采集记录在 `data\终版4K60采集记录.json`。

## 修改航线和解说

- 镜头位置、走向、停留时间在 `tools\flight_route.py`。建筑锚点在 `data\locations.json`，左下角文案和出处在 `data\海岸航线解说.json`。
- 修改后在工程根目录执行下列两条命令。第一条重建 30 fps 基准航线，第二条也会检查 60 fps 的逐帧采样。确认后双击采集入口出片。
- 采集器位于 `tools\bay_film\`。字幕布局和每帧合成在 `capture.js`，分片、合并与成片验收在 `capture.py`。分镜索引见 `preview\海岸航线分镜.jpg`。

~~~powershell
& ".\运行环境\Python\python.exe" -B -X utf8 ".\tools\prepare_bay_flight.py"
& ".\开始采集校园漫游.cmd" --check
~~~

## 修改模型

Blender 中直接编辑的内容请另存为新的 .blend。正式视频读取离线网页内嵌的 GLB，手工修改 .blend 后，已有网页仍显示导出时的场景。

若要让网页版、可编辑模型和影片采用同一套新模型，修改 `tools\qd_*.py`、`tools\build_campus.py` 或 `data\` 中相应的参数，再运行 **重建模型.cmd**。脚本在同级新目录依次生成夕照 HDR、GLB、六处窗景的两套反射图、离线网页和新的 .blend。可以先用 `.\重建模型.cmd --check` 检查依赖；带空格的输出目录请加引号。改动楼的位置后，也请在新工程中重新生成航线并检查镜头。

~~~powershell
& ".\重建模型.cmd" --output "D:\山青\建筑修订 01"
~~~

## 素材与运行条件

| 位置 | 用途 |
| --- | --- |
| `assets\` | 夕照环境、地表底图和用于玻璃反射的校园窗景 |
| `data\map\`、`data\terrain\`、`data\` | 校园地物、地形瓦片、位置、楼名题字轮廓和建模参数 |
| `实景参照\` | 校方与用户提供的建筑、海岸和花木照片，以及原视频参考帧，保留建模采色所用原文件名 |
| `viewer\`、`山东大学青岛校区.glb` | 离线浏览器的源码与可交换三维模型 |
| `建模说明.md`、`参照模型\` | 建模依据、项目所用资料来源及鼓楼建筑参照 |
| `运行环境\` | Windows x64 便携工具与库，含 Python 3.11、bpy 4.3、Chrome、FFmpeg、FFprobe |

交互式 Blender 桌面编辑请使用 Blender 4.3 或兼容版本。Windows 上重建模型需要黑体、微软雅黑、Arial 和 Arial Bold，视频字幕使用本机中文字体。底图与影像出处保存在建模说明、数据来源表和原始写真目录中。
